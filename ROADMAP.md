## Phase 1 `Prototype (2023)`
 - [x] **Initial Release** `0.0.1`
    - Basic AIO.php monitoring prototype with MD2 styling.

## Phase 2 `Rebirth & Modernization`
 - [x] **Project Rebirth** `1.0.0`
    - Full MD3 modernization.
    - Implementation of TCP Pinging and Statuspage monitoring.
    - Background monitoring service.
 - [x] **Localization & Optimization** `1.0.1`
    - Translation engine implementation.
    - UI/UX performance optimizations.
 - [x] **UI Polish & Onboarding** `1.0.2`
    - Horizontal component layouts.
    - Markdown support for status updates.
    - Improved intro flow with demo service selection.
 - [x] **Translation & Stability** `1.0.3`
    - Finalizing Ukrainian localization.
    - Critical bug fixes for server detail views.
